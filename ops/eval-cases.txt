# Cases for ops/eval.py. Each case is a question, then checks on the bot's answer:
#   must: a regex the answer has to match       not: a regex it must not match
#   max:  the most characters the answer may be
# Regexes are case-insensitive. Cases are separated by blank lines.
#
# must: only for facts the answer needs (a date, an amount, a name, a link), never for wording;
# not: for what would mislead or harm. A check that fails a correct answer gets simplified or
# deleted, not given another alternative.
#
# regression: wrong answers here would mislead or harm someone. Every run must pass; a failure
#   blocks deploy.sh.
# capability: known weak spots we want to improve. Reported, never blocking.
